Tags Básicas

<h1> ao <h6>: Definem a hierarquia de títulos.

<p>: Utilizada para criar parágrafos.

<br>: Insere uma quebra de linha.

<ul>: Cria uma lista não ordenada.

<ol>: Cria uma lista ordenada.

<li>: Define um item de uma lista.

<div>: Agrupa elementos HTML.

Links e Imagens

<a href="...">: Tag âncora usada para criar hiperlinks.

href: Define o destino do link.

target="_blank": Abre o link em uma nova aba.

target="_self": Abre o link na mesma aba.

<img>: Utilizada para inserir imagens.

src: Define o endereço da imagem.

alt: Descreve a imagem.

Links Absolutos e Relativos

Links Absolutos

Possuem o endereço completo, incluindo protocolo e domínio. São utilizados para acessar páginas externas.

Exemplo:

Repositório do Linux

Links Relativos

Dependem da localização do arquivo atual na estrutura de pastas.

./ Representa a pasta atual.

../ Sobe um nível na estrutura de diretórios.

Exemplos:

contato.html - Arquivo na mesma pasta.

../assets/logo.png - Sobe uma pasta e acessa a pasta assets.

Links de Fragmento (Âncoras)

Utilizam o símbolo # para direcionar o usuário a uma parte específica da mesma página.

Para funcionar, o destino precisa possuir um atributo id.

Exemplo:

<a href="#arquitetura">Arquitetura</a>

<section id="arquitetura">

O navegador realiza essa navegação diretamente, sem enviar o fragmento ao servidor.

Segurança e Acessibilidade

Segurança com target="_blank"

Quando um link abre em uma nova aba, pode existir o risco chamado Reverse Tabnabbing.

Para evitar esse problema, utilizamos rel="noopener noreferrer".

noopener: Impede o acesso à página original através de window.opener.

noreferrer: Impede o envio da informação de referência da página anterior.

Acessibilidade (A11y)

Os textos dos links devem indicar claramente para onde o usuário será direcionado.

Evite expressões genéricas como "Clique aqui".

Prefira textos descritivos, como "Consultar documentação oficial do HTML".
